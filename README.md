# Shenzhen Living Will

Design research study on living wills and end-of-life decisions in Shenzhen.

Static HTML and CSS, with all images stored alongside the page. No installation or build step is needed. Open `index.html` in a browser to preview, or serve this folder with `python3 -m http.server 8000`.

The **Play** button opens https://xuefengli7788.github.io/dianyun/.

For GitHub Pages, select **Settings → Pages → Deploy from a branch → main → / (root)**.

This copy was exported from the existing Shenzhen Living Will website. Edit `index.html` for content, `base.css` for shared styles, and `design.css` for the section layouts.
